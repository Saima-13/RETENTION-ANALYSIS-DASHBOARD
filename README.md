
# 📊 Customer Churn & Retention Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Customer Churn & Retention Analysis Dashboard** designed to analyze customer behavior, identify churn patterns, and uncover the factors associated with customer attrition.

The dashboard provides a comprehensive view of **7,043 customers**, focusing on demographics, services, contracts, payment methods, and customer account characteristics.

The goal of this project is to transform raw customer data into meaningful business insights that can help organizations understand **why customers churn and how customer retention can be improved**.


## 🎯 Objectives

* Analyze overall customer churn patterns.
* Identify customer segments with higher churn.
* Compare churn across different services.
* Analyze churn based on contract type.
* Understand the relationship between payment methods and churn.
* Compare churn behavior by gender and partner status.
* Examine customer usage of internet, phone, streaming, and security services.
* Present insights through an easy-to-understand visual dashboard.

## 💡 Key Insights

Some notable observations from the dashboard include:

* A significant number of churned customers do not have **Online Backup** or **Online Security** services.
* Customers using **Fiber Optic** internet service represent a large portion of the churned customer base.
* **Month-to-month contracts** account for substantially more churn than longer-term contracts.
* Customers using **Electronic Check** as their payment method show a comparatively high number of churned customers.
* Churn can be analyzed across multiple service combinations to identify higher-risk customer segments.
* Gender distribution is relatively balanced, making gender alone less useful as a primary churn indicator.
* Streaming and internet-service choices provide additional segmentation opportunities for retention strategies.
